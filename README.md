🍔 Dev-Burguer

📌 Sobre o projeto

O Dev-Burguer é um projeto desenvolvido durante meus estudos de JavaScript, com o objetivo de praticar e aplicar quatro importantes métodos de manipulação de arrays: forEach(), map(), reduce() e filter().

Através de uma lista de produtos de uma hamburgueria, desenvolvi funcionalidades que permitem exibir os produtos, aplicar descontos, calcular valores e filtrar produtos veganos.

🚀 Funcionalidades

forEach(): Percorre o array de produtos e exibe todos os itens na tela.

map(): Cria um novo array de produtos aplicando 10% de desconto em todos os preços, sem modificar o array original.

reduce(): Percorre os produtos e calcula a soma total dos preços.

filter(): Filtra os produtos utilizando a propriedade vegan, exibindo somente os produtos veganos.
